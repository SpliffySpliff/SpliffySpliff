# Lead-Pipeline — Envy

Tags:: #pipeline #envy #tracking

Lebende Tabelle aller Leads. Update wann immer sich der Status ändert.

## Status-Definitionen

| Status | Bedeutung |
|---|---|
| **Cold** | Lead gefunden, noch nicht kontaktiert |
| **Outreach 1** | Erstkontakt versendet, warte auf Antwort |
| **Outreach 2** | Follow-up versendet (1×, dann Ruhe) |
| **Antwort** | Lead hat geantwortet, Konversation läuft |
| **Audit** | Mini-Audit verschickt |
| **Call** | Discovery-Call durchgeführt |
| **Handoff** | An Envy übergeben |
| **Angebot** | Envy hat Angebot gemacht |
| **Auftrag 🎉** | Auftrag erteilt, Provision-Trigger |
| **Tot ❌** | Lead hat abgelehnt / antwortet nicht / passt nicht |
